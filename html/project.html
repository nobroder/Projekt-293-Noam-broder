BLJ CRM

Das BLJ CRM ist ein Kundenverwaltungssystem, das ich im Rahmen meines ersten Lehrjahres entwickelt habe. Die Applikation ermöglicht es, Kundendaten übersichtlich zu verwalten, neue Kontakte hinzuzufügen und bestehende Einträge zu bearbeiten. Umgesetzt habe ich das Projekt mit HTML, CSS und JavaScript – dabei habe ich besonders gelernt, wie man Formulare verarbeitet und Daten strukturiert speichert. Das CRM war mein erstes grösseres Webprojekt und hat mir gezeigt, wie wichtig eine klare Datenstruktur und eine intuitive Benutzeroberfläche sind.

Surf Shop

Der Surf Shop ist eine vollständige E-Commerce-Webseite für einen fiktiven Surfausrüster. Die Seite beinhaltet eine Produktübersicht, eine Detailansicht für einzelne Artikel sowie einen Warenkorb. Das Projekt habe ich mit HTML und CSS umgesetzt und dabei viel über responsives Design und moderne Layouttechniken wie Flexbox und Grid gelernt. Besonders herausfordernd – und lehrreich – war es, ein einheitliches Design durchzuhalten und die Seite auf verschiedenen Bildschirmgrössen funktional zu halten.

To Do Tool

Das To Do Tool ist eine browserbasierte Aufgabenverwaltung, die ich mit HTML, CSS und JavaScript entwickelt habe. Aufgaben können erstellt, als erledigt markiert und wieder gelöscht werden – alles ohne Seitenneuladen, dank dynamischer DOM-Manipulation. Das Projekt hat mir gezeigt, wie mächtig JavaScript im Browser ist und wie man mit einfachen Mitteln eine nützliche, interaktive Anwendung baut. Durch die Arbeit am To Do Tool habe ich meine JavaScript-Kenntnisse deutlich vertieft und erste Erfahrungen mit dem localStorage gesammelt.
