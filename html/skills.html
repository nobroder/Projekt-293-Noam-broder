HTML/CSS

HTML und CSS waren meine ersten Schritte in die Webentwicklung. Ich habe gelernt, wie man eine Webseite strukturiert, sie mit Styles verschönert und responsiv gestaltet, damit sie auf jedem Gerät gut aussieht. Flexbox und Grid sind heute meine besten Freunde, wenn es darum geht, Layouts zu erstellen. Dieses Portfolio ist ein gutes Beispiel meiner bisherigen Kenntnisse – vollständig in HTML und CSS gebaut, ohne Framework.

Java

Java war meine erste richtige Programmiersprache und hat mir das Denken in Klassen und Objekten beigebracht. In der Schule und im Betrieb habe ich damit einfache Programme, Algorithmen und datenverarbeitende Applikationen entwickelt. Auch wenn Java manchmal etwas geschwätzig wirkt, schätze ich die klare Struktur und die Typsicherheit, die mir hilft, Fehler früh zu erkennen. Das objektorientierte Denken, das ich durch Java gelernt habe, hilft mir in allen anderen Sprachen.

JavaScript

JavaScript hat mir eine ganz neue Welt geöffnet – plötzlich wurden meine statischen HTML-Seiten lebendig. Mit JavaScript kann ich Benutzerinteraktionen verarbeiten, Inhalte dynamisch ändern und meinen Webseiten echtes Leben einhauchen. Die Hamburger-Navigation auf dieser Seite ist zum Beispiel komplett in JavaScript gebaut. Ich freue mich darauf, JavaScript immer tiefer zu erlernen und bald auch mit modernen Frameworks zu arbeiten.
